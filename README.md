# Ludo Blaze — privacy policy

The public privacy policy for the Android game **Ludo Blaze**
(`app.ludoblaze.ludo`), served by GitHub Pages at:

**https://neelesh118-web.github.io/ludoblaze-privacy/**

## Why this repository exists on its own

Google Play requires a public URL for the privacy policy of any app that
collects data, and Ludo Blaze uses Google AdMob. The policy itself is authored in
the game's own repository at `docs/PRIVACY.md`, which also holds internal design
records and release plans that are not meant to be public — so publishing that
repository's `docs/` folder was not an option. This repository holds the
published page and nothing else.

## Editing

`index.html` is the whole page: one file, no scripts, no cookies, no external
resources, so it loads on anything and cannot break when a CDN moves. Edit it,
then push to `main`; Pages rebuilds in about a minute.

When the policy changes, update the "Last updated" date on the page and the same
line in `docs/PRIVACY.md` in the game's repository, so the two do not drift.
